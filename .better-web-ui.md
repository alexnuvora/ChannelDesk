# ChannelDesk design context

## Audience
Social media managers, creators, small-business teams and agencies managing multiple channels from one workspace.

## Brand direction
ChannelDesk uses a TikTok-inspired product language without copying TikTok branding or protected assets: bright white surfaces, near-black typography, cool neutral greys, compact information density and sparing cyan/pink energy accents. It should feel social, current and fast rather than corporate, editorial or generic AI SaaS.

## Typography
Use a clean highly-legible grotesk/sans-serif system. Inter is the open web font currently used as the practical ChannelDesk approximation. Headlines are bold but not oversized; avoid decorative display faces, excessive tracking and all-caps except tiny utility labels.

## Color
Primary canvas #FFFFFF. Primary text #161823. Secondary text #4F515A. Borders #E3E3E6. Primary action/accent #FE2C55. Cyan #25F4EE is a secondary signature accent used very sparingly. Never return to beige/cream/chartreuse, purple AI gradients, glassmorphism or dark-everywhere dashboards.

## Components
Prefer white surfaces, subtle grey borders, 4–12px radii, crisp controls and compact lists. Use cards only when grouping materially helps comprehension. Primary actions use the pink/red accent; ordinary navigation stays black/grey. TikTok network marks can use cyan/pink shadow cues, while ChannelDesk remains its own brand.

## Product principles
Hierarchy before decoration. One obvious primary action per surface. Common actions stay close to their content. Status uses text/icon/shape as well as color. Critical functionality remains reachable on mobile. Empty states teach the next action. Never imply integrations or features that are not implemented. Preserve accessibility, keyboard focus, responsive behavior and reduced-motion support.
